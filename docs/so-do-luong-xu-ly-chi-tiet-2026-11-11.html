2. Luồng chi tiết POST /api/audio/translate — có chia tải 2 tài khoản

Diễn giải từng bước

  1. Client gửi audio qua HTTPS → Nginx host → load balancer chọn backend đang ít kết nối hơn.
  2. Backend kiểm tra quyền, giới hạn hàng chờ và tổng dung lượng upload đang giữ (32 MB) để không bị tràn RAM khi đông người.
  3. Xem redis-cache: audio đã dịch gần đây thì trả ngay, không tốn lượt Cloudflare.
  4. Chưa có: dispatcher chọn tài khoản cho bước ASR (xoay vòng, ưu tiên tài khoản ít tải), xin permit ở redis rồi gọi Whisper.
  5. Kiểm tra transcript, rồi chọn tài khoản lại cho bước dịch, độc lập với bước ASR.
  6. Lưu kết quả vào cache, trả bản dịch kèm audioUrl có ?node=3000|3001.
  7. Song song: tạo giọng đọc tiếng Anh chỉ trên audio-a; client mở audioUrl → nginx đưa về đúng backend đang tạo → nghe ngay; file được lưu lên Cloudinary.

4. Production và dev trên cùng VPS

Production Nginx Docker + backend-3000, backend-3001, audio-worker · 3 Redis riêng · deploy từ nhánh can-bang-tai
Dev Nginx Docker + 1 backend (1 GB, 0,75 CPU) · 3 Redis riêng · deploy từ nhánh dev
Dùng chung CPU / RAM / ổ đĩa VPS · phần mềm Docker · Nginx host · Neon PostgreSQL
Rủi ro cần nhớ:
• Hạn mức Cloudflare: Redis dev và prod tách riêng nên bộ đếm cũng tách. Nếu dev bật pool với cùng 2 tài khoản, mỗi bên tưởng mình có toàn bộ hạn mức → tổng có thể vượt hạn mức thật. Cho dev dùng tài khoản/token khác hoặc đặt limits thấp hơn.
• audio-a là điểm nghẽn: mọi tính năng cũ và mọi TTS đều dồn vào A. Muốn các API khác cũng được chia tải phải đưa chúng qua dispatcher pool và khai báo TTS cho audio-b.
• Database dùng chung: dev ghi/xoá hoặc chạy migration sẽ tác động thẳng vào dữ liệu thật của prod.
Thông số đang dùng (theo .env.example / .env.local): tối đa 2 lần thử mỗi bước, 3 lần mỗi request · chờ suất tối đa 5 s · 20 request audio đang xử lý và 40 request chờ mỗi backend · bộ nhớ upload 32 MB mỗi backend · timeout ASR mỗi lần thử 8 s, dịch 6 s, hạn chót tổng ~20 s · thử lại lỗi tạm thời bật (CLOUDFLARE_POOL_RETRY_TRANSIENT=true, có thể bị tính tiền 2 lần ở Cloudflare).
